# 私人配置美国单落地与六地区入口（2026-10-31）

本文仅为历史归档，全部链式方案已于 2026-11-07 撤销；不得据此恢复配置或验收。现行约定见 [美国机场节点方案](us-airport-direct-20261107.md)。

用户撤销 2026-10-30 早期三个出口方案，并明确要求全部私人客户端接入新美国单落地。六份文件包括两份 FlClash、Clash Mi iOS、两份 Surge Personal 与 Surge 工作白名单。香港恢复普通机场节点，不设香港链式前置。真实地址和认证仅存独立私人仓库；旧方案由 Git 历史追溯，不得拿旧测试作为本轮证据。

| 入口 | 最终路径 |
| --- | --- |
| AI、Microsoft 美国候选、Store、六地区菜单的美国 | 美国最终组 → 唯一 RM-US-Exit |
| 美国节点拨号 | 美国线路入口 → 经所选地区接入 → 该地区机场自动节点 |
| Google 默认、Notion、香港地区 | 普通香港机场；安卓保留手动 select 与历史隔离 |

| 地区例外 | Crypto 台湾、日本精确入口；Microsoft DIRECT 选项保留 |
| 普通全地区自动/手动组 | 保留原用途，不限制在美国或香港 |

界面只显示一个 `美国线路入口`，选项顺序固定为 `经香港接入`、`经台湾接入`、`经新加坡接入`、`经日本接入`、`经美国接入`、`经韩国接入`，首次加载默认香港。用户选择接入地区，地区内部自动选择机场节点，最终出口始终是购买的美国 IP。六个辅助组保持隐藏，避免首页再次出现六张前置卡片；客户端实际展示须导入后另验。

Mihomo 六个入口均为 url-test，use 包含全部已登记 provider，按地区 filter 筛选并排除套餐占位项；安卓香港入口额外保留历史精确隔离。桌面检测周期为 300 秒，安卓和 iOS 为 600 秒，lazy true，美国 tolerance 100、其他 50。Surge 主组显式引用六个入口，每个入口用 include-other-group 读取七个机场来源、include-all-proxies=0、对应地区 policy-regex-filter、interval=300、hidden=1。入口不能引用业务组、最终落地、DIRECT 或其他入口，避免环路。

美国最终组显式隐藏，历史名称“美国-自动选择”仅保留兼容业务引用；它只封装一个 RM-US-Exit，并没有多 IP 自动切换。RM-US-Exit 是美国 SOCKS5 落地本身。AI 和 Microsoft 的美国候选共享 `美国线路入口`；改名后须更新客户端配置并重新保存地区选择。香港作为美国线路入口，不改变 Google、Notion 或香港券商的普通机场业务路径。

2026-10-31 纠正与防复发：此前六张可见卡片过多，直接展开美国节点又不符合最新的地区选择需求。当前只让主组可见，六个隐藏入口独立筛选各自地区，不复用可能包含美国落地的业务组。检查器保护六项顺序、可见性、完整机场来源、检测周期、地区过滤与无环约束。短国家代码使用词边界（US 不匹配 RUSSIA、AUS、BUS），provider 前后缀不能注入地区标签。运行态也逐个交叉核对六组与真实 provider 节点；标签筛选仍不等于实际 IP 地区和线路健康验收。

美国只有一成员，不再做流量分摊。Mihomo 保留单节点 `load-balance` 封装与 `udp: false`：TCP-only Selector 的 SupportUDP=false 可能导致匹配器跳过规则并落入 DIRECT，单节点 LB 保持匹配后失败。禁止 disable-udp。Surge 的单节点 select 使用 SOCKS5 underlying-proxy，显式 `udp-relay=false` 和 `[General] udp-policy-not-supported-behaviour = REJECT`。UDP 能力未经确认，不虚报支持；TCP 回退、语音、视频须实机验收。

默认国内 DNS、AI 海外 DoH 经美国出口、安卓 Google/YouTube DNS 跟随业务选择保持。供应商端点是 IP，无新增节点域名 bootstrap。工作版只调整既有美国入口的代理路径，规则节、白名单、最终 REJECT 不扩大。iOS 先构建再由桌面派生，保留 600 秒、进程 off、应用管理 TUN 和 DNS 基线。
