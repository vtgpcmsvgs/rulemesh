# 2026-09-16 FlClash 桌面实测

手机已断开；用户确认本机不经过局域网 Surge。本次对象是正在运行的 Windows FlClash、它的实际配置和同版本隔离内核。手机与 Mac 的配置关联检查不等于设备运行验收。

## 结论与修复

确认一个规则漏项：NotebookLM 已跳转到 Gemini Notebook 的 `notebook.google`，页面产品入口为 `notebook.google.com`。两者已加入 `ai_us` 的精确域名后缀，继续使用美国出口及 AI 专用解析。保留旧域名；增加产品正例、伪后缀反例和常用业务首条命中回归。五份私有配置和两份公开模板共用该规则资产，无需改写私有订阅或扩大 Google 根域。

路由结构和客户端加载没有发现新的广谱误分流：国内业务仍直连，WPS/金山文档香港、Store/AI 美国、Crypto 台湾、日本入口、香港券商的地区要求保留。没有把网络失败解释为必须恢复全局海外 DNS、关闭证书校验或放宽工作白名单。

**本次不能判定所有业务均稳定可用。** 实测仍有节点或代理链路相关的超时、TLS 失败和站点限制。规则命中正确、Google 测速成功、站点返回 HTTP 三者不是同一项验收。

## 测试覆盖与证据

- 对 69 个常用国内外入口做 TUN、显式 HTTP 代理、SOCKS5 域名代理对照。五轮矩阵共 555 次请求，另做解析、地区出口、同节点和同地区候选对照；使用连接/总耗时截止与响应大小上限。
- 后一轮 22 个重点入口、66 次请求中，53 次完成已验证 TLS 并收到目标响应或部分正文，13 次传输失败。国内十个重点入口的 30 次全部完成传输；403/429 等站点响应独立归类，HTTP 200 部分下载也不冒充完整业务成功。
- 初始和收尾分别核对私有源、选中 profile、FlClash 生成配置、规则资源缓存及实际运行态。初始三者的规则、明确 DNS 字段和策略组一致；临时诊断不写入私人源文件。
- 实际连接记录确认 Google、GitHub、WPS、Crypto 等命中各自预期组。显式域名代理样本的目标 IP 未在客户端连接元数据中预先解析，不能仅凭客户端普通 DNS 查询异常就断定这些请求已使用该答案。
- 同版本隔离内核绑定物理接口、关闭 TUN，按当前选择复制节点。最新一轮两种独立地理服务分别确认 DIRECT 为中国大陆，AI 美国、WPS 香港、Crypto 台湾、日本组的地区正确。该结果只代表当时节点快照，不保证所有候选标签都准确。
- 同节点生产/隔离对照复现 WPS 超时、Polymarket TLS 失败后恢复；关闭和恢复嗅探未消除失败。因此未将故障归因于 TUN 或通过关闭嗅探修改长期配置。
- 同地区候选中出现 Google HTTPS 204 成功、WPS 超时的香港节点，以及 Google 204/OKX 成功、Polymarket 证书校验失败的台湾节点。说明通用测速不能证明所有业务兼容；一次短样本也不足以永久删除机场、节点或协议。

## DNS 对照的边界

国内 DoH 对 Google、Polymarket 的部分回答与海外 DoH 不同；Google 的部分国内答案不在仓库维护的官方 Google IP 清单。DNSPod 的 JSON 与 RFC 8484 二进制接口也出现差异，不能用 JSON 接口的成功替代生产 DoH 验证。

最初的固定地址 HTTPS 对照看似全部成功，但补充阴性对照发现：向文档保留地址发送同一 Google SNI，代理仍能取得 Google 有效响应。这说明代理链会按域名重新选择目的地，该方法不能证明指定 IP 正确，也不能证明本地 DNS 没有问题。保留此证据缺口，不将地址差异单独判定为故障原因。

普通国内双 DoH、国内节点 bootstrap 和 AI 美国专用 policy 保持。运行验收需要同时观察 DNS 出口、业务出口及重定向目标；涉及真实 IP 的对照必须先证明代理不会改写目标。

## 可复用的排错约束

1. 先分离规则、客户端覆写、DNS、节点、站点风控与业务登录，不用一个 HTTP 成功率代替所有层次。
2. 通用 204 测速之后仍须验证实际业务；TLS 35/60、连接超时、HTTP 403/429、下载达到大小上限和 HTTP 200 后的部分下载分别记录。证书失败不通过关闭验证处理。
3. API 返回成功后必须核对生成配置、实际端口和行为。FlClash 本次会丢弃 profile 中的临时 `listeners`；不能把配置 API 成功响应视为监听器已生效。
4. 同版本隔离内核必须使用独立任务目录、随机私有 IPC、显式 `startListener`，并在 finally 中退出；provider 缓存原名需应用 override 前后缀后才对应运行节点身份。准备失败即停止，不运行旧快照。
5. 重定向终点加入验收。产品更名不能靠品牌关键词扩围，应核对归属后补精确域名，并加入相似名称反例。

公开文档仅保留业务域名、分类结果与方法；真实订阅、节点身份、出口 IP、控制器秘密和配置快照只在本机私人诊断目录。结束时撤销临时控制器及秘密，恢复源文件精确字节，保持 FlClash 和电脑运行。
